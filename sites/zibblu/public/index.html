02 — Private LAN

Some things
stay between us.

On a reachable local network, invite another verified device into a separate, authenticated, encrypted text session. Messages move directly over LAN—never through an online message relay.

Direct LAN transport No cloud relay and no silent internet fallback.
In-memory text only Excluded from ordinary chat history, logs, and cloud AI.
Read private chat security boundaries ↗
A CLEAR DISTINCTION

Ordinary chats use your selected online server and are not end-to-end encrypted. Private LAN text is a separate, opt-in mode with no internet fallback; ending it clears app-managed in-memory text, not screenshots or OS traces.

03 — Your assistant

Ask about what matters.

Mention a configured assistant with @name inside an ordinary chat. Pick the exact messages and optional text files for that single request, review the provider disclosure, and send.

  • One-shot authorization: Every request requires explicit context approval—no background collection.
  • Strictly read-only: Assistants cannot edit history, modify local files, or execute commands.
  • LAN isolation: Private LAN sessions are completely excluded from cloud AI requests.
